# 🧳 行李打包清單

一個以 **HTML + JavaScript** 製作的輕量化行李打包工具，適合個人與家庭旅遊、比賽、出差等情境使用。

本工具的設計目標，是取代傳統「每趟旅程複製一份清單」的做法，改用：

- 一份可長期維護的「總清單」
- 每趟旅程獨立設定「誰要帶什麼」
- 每位旅客擁有自己的打包看板
- 支援個別註解、共用物品、CSV 批次匯入與分享版 HTML

目前版本：**v1.5.1**

---

## ✨ 主要功能

### 1. 旅程管理

可建立、編輯、刪除旅程，並記錄：

- 旅程名稱
- 日期
- 日期說明
- 幾天幾夜
- 旅客名單
- 參考／套用其他旅程的準備項目

旅程預設依日期由新到舊排序。

也可點擊 `★` 將重要旅程置頂，再點一次即可取消置頂並恢復預設排序。

---

### 2. 總清單

所有可能會用到的物品，只需維護一份總清單。

每個物品包含：

- 物品名稱
- 類別

類別可獨立管理，可新增、改名、刪除。

左側類別同時具備篩選功能，點擊類別即可只顯示該分類的物品。

總清單支援：

- 單筆新增
- 編輯物品名稱與類別
- 刪除物品
- CSV 批次匯入
- CSV 範本下載
- 類別篩選
- 類別排序

---

### 3. 應準備

每趟旅程不需要複製整份清單，而是在總清單上勾選「這趟要帶什麼」。

每個物品可指定：

- 爸爸
- 媽媽
- 哥哥
- 妹妹
- 其他旅客
- 共用

個人物品可同時指定多人。

每個「物品 × 人物」都可以有自己獨立的註解，例如：

```text
褲子
爸爸：黑色休閒長褲
哥哥：球隊運動長褲
```

「應準備」頁籤也支援依類別篩選，避免清單過長時難以尋找。

---

### 4. 打包看板

每位旅客都有自己獨立的打包看板。

例如：

- 爸爸
- 媽媽
- 哥哥
- 妹妹
- 共用

切換到某個人後，只會看到該人物品，不會混入其他人的清單。

物品依類別分成不同 List，並使用不同淡色系背景，方便視覺辨識。

每張卡片可顯示：

- 物品名稱
- 個別註解
- 是否已打包

並提供：

- 應準備數量
- 已打包數量
- 完成率

---

### 5. 分享版 HTML

整理完旅程後，可直接產生「分享版 HTML」。

產生時可指定分享對象，例如：

```text
哥哥
```

並可選擇是否一起加入：

```text
共用項目
```

例如匯出的檔名可能是：

```text
2026西灣盃_哥哥_行李打包清單_分享版.html
```

或：

```text
2026西灣盃_哥哥_含共用_行李打包清單_分享版.html
```

分享版特色：

- 直接打開即可使用
- 不需要匯入 JSON
- 只包含指定旅程
- 只包含指定人物
- 可選擇是否包含共用看板
- 適合放在 Google Drive、雲端硬碟或直接傳給家人

---

### 6. JSON 備份與還原

目前主要資料儲存在瀏覽器的 `localStorage`。

因此工具提供：

- 匯出 JSON
- 匯入 JSON

建議定期匯出 JSON 作為備份。

---

## 📦 CSV 批次匯入格式

總清單支援 CSV 匯入。

CSV 至少需要以下兩欄：

```csv
名稱,類別
手機,隨身用品
充電線,3C用品
黑色長褲,衣物
```

匯入時：

- 新類別會自動建立
- 相同「名稱 + 類別」的項目會略過
- 空白列或缺少欄位的資料會略過
- 匯入完成後會顯示處理結果

---

## 💾 資料儲存方式

目前版本使用瀏覽器的：

```text
localStorage
```

也就是說：

- 同一台裝置、同一個瀏覽器可持續保存資料
- 重新整理網頁不會清空資料
- 更新 GitHub Pages 網頁通常不會影響既有資料
- 不同裝置之間不會自動同步
- 清除瀏覽器網站資料可能會刪除資料

因此重要資料請定期使用「匯出 JSON」備份。

## 🌐 GitHub Pages 部署

本工具是純前端靜態網頁，可以直接部署到 GitHub Pages。

建議 repository 中將正式檔案命名為：

```text
index.html
```

典型架構：

```text
packing-list/
├─ index.html
└─ README.md
```

GitHub Pages 設定：

```text
Settings
→ Pages
→ Build and deployment
→ Deploy from a branch
→ main
→ / (root)
```

完成後即可使用固定網址，例如：

```text
https://你的帳號.github.io/packing-list/
```

## 🖥️ 使用方式

### 建立旅程

1. 進入「旅程」
2. 點擊「＋ 新旅程」
3. 填寫旅程名稱、日期、幾天幾夜與旅客
4. 必要時套用舊旅程的應準備項目

### 整理應準備清單

1. 進入「應準備」
2. 使用類別篩選
3. 點選每個物品的打包人
4. 填寫個別註解

### 實際打包

1. 進入「打包」
2. 選擇人物
3. 按照各分類 List 整理行李
4. 完成後勾選「已準備」

### 分享給家人

1. 點擊「產生分享版 HTML」
2. 選擇分享對象
3. 決定是否加入共用項目
4. 產生 HTML
5. 將檔案放到雲端硬碟或傳給家人

## 🔐 隱私

目前版本沒有後端伺服器，也不會主動把旅程資料上傳到外部資料庫。

資料主要保存在：

```text
你的瀏覽器 localStorage
```

分享版則是將指定資料直接寫入獨立 HTML 檔案中。

## 📌 設計理念

本工具不是單純的「勾選清單」，而是將：

```text
總清單
→ 旅程
→ 旅客
→ 應準備
→ 個別註解
→ 打包進度
```

拆成清楚的資料層級。

目的在於讓一份總清單可以長期維護，而每趟旅程只需要記錄「這次真正要帶什麼」。
